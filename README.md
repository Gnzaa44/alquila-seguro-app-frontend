# Alquila Seguro - Frontend

Interfaz web moderna y responsiva para plataforma de gestión de alquileres 
temporarios.

🔗 **En producción:** [alquilaseguro.com.ar](https://alquilaseguro.com.ar)

## Stack Técnico

- **Framework:** React.js
- **Estilado:** Bootstrap, CSS3
- **Routing:** React Router
- **HTTP Client:** Axios
- **Diseño:** Mobile-first, responsive

## Características

- Interfaz intuitiva con validaciones en tiempo real
- Formularios optimizados para UX
- Diseño responsivo (mobile/tablet/desktop)
- Integración con backend RESTful
- SEO técnico optimizado

- ✅ Compatible con todos los navegadores modernos
